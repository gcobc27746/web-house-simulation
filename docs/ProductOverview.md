# 產品總覽

## 核心理念

* **2D 階段解決「比例尺正確 + 牆線正確」**
* **3D 階段解決「空間尺度感 + 走動體驗」**
* 不追求自動辨識，而是追求 **可控、可校正、可驗證**

本產品的核心目標，不是建立華麗的 3D 模型，而是建立一個「可被信任」的空間決策工具。

2D 階段的價值在於：

* 確保比例尺正確
* 建立乾淨、可運算的向量模型
* 消除圖片視覺誤差

3D 階段的價值在於：

* 驗證空間尺度感
* 驗證走動與視角體驗
* 提供可重複檢視的沉浸式空間瀏覽

---

# 功能 1：2D 平面圖校正與牆線標註（Floorplan Editor）

## 1.1 主要目的

把「一張圖片」變成「有真實比例的 2D 平面底圖」，並在上面完成：

* 比例尺校正（Scale Calibration）
* 牆線向量化（Wall Tracing）
* 產生可被 3D 引擎使用的結構資料

本階段不依賴 AI 自動辨識，而是透過使用者明確操作，確保最終資料精準可控。

完成後應產出：

* 以公尺為單位的 polygon 外框
* 已校正的比例資訊
* 可被序列化為 JSON 的結構資料

此資料將作為後續 3D 生成的唯一來源。

---

## 1.2 使用流程（UI Flow）

### Step A：上傳平面圖

* 支援格式：JPG / PNG
* 上傳後顯示於 2D 畫布（Canvas）中
* 可拖曳定位與縮放

---

### Step B：比例尺校正（以玄關門 90cm 為例）

提供「校正工具模式」：

1. 使用者點擊兩點量測（例如門框左右兩側）
2. 輸入真實距離：`0.9 m`
3. 系統計算 px → meter 比例
4. 鎖定整張圖的比例尺

#### UI 細節建議

* 顯示目前縮放比例（例如：`1px = 0.0032m`）
* 顯示量測線長度（px 與 m 同時顯示）
* 提供「重新校正」按鈕
* 可多次校正以驗證誤差

---

### Step C：牆線標註（Wall Drawing）

提供牆線工具（以手動畫牆為主）：

#### 牆線繪製模式

* 點一下起點 → 點一下終點（形成一段牆）
* 可連續畫（類似 polyline）
* 支援吸附（snap）：

  * 吸附到端點
  * 吸附到水平 / 垂直（按住 Shift 強制對齊）

#### 牆厚設定（第一版採全域設定）

* 全域牆厚（預設 10cm 或 12cm）
* 後續版本可支援單段牆不同厚度（非 MVP 範圍）

#### 編輯能力（必要功能）

* 選取牆段 → 移動端點
* 刪除牆段
* Undo / Redo
* 自動檢查 polygon 是否封閉

---

### Step D：完成 2D 建立 → 產生結構資料

按下「完成」後，系統不輸出圖片，而是輸出結構化 JSON（概念如下）：

* floorplan scale（px → meter）
* wall segments / polygon 頂點資料
* wall thickness
* optional：門洞 / 窗洞（第一版可不實作）

所有座標轉換為公尺單位，確保 3D 階段不依賴圖片。

---

## 1.3 2D 功能驗收標準（KPI）

1. 使用者校正後，任意再量測一段已知尺寸（例如另一扇門或床寬），誤差 < 2–3cm
2. 牆段可完整封閉形成主要空間外框
3. 可下載 JSON 並再次載入進行編輯
4. polygon 不可自交叉，幾何結構合法

---

# 功能 2：2D → 3D 轉換與空間瀏覽（3D Viewer）

## 2.1 主要目的

將已建立的 2D 外框 polygon 轉換為 3D 空間模型，並提供可控制攝影機的沉浸式瀏覽功能。

本階段解決的核心問題為：

* 空間尺度感是否合理
* 走動時的壓迫感與開闊感
* 牆高與比例是否符合預期

## 2.2 使用流程

1. 使用者輸入天花板高度（Ceiling Height）
2. 系統根據 2D polygon 生成：

   * 地板
   * 牆體（依設定牆厚向內或向上拉伸）
3. 建立第一人稱攝影機
4. 提供 WASD + 滑鼠視角控制
5. 啟用碰撞偵測，避免穿牆

## 2.3 生成原則

* 所有 3D 幾何均來自 2D 結構資料
* 不依賴原始圖片
* 不進行任何自動推測
* 僅基於使用者明確定義的向量資料進行 extrusion

## 2.4 本階段完成後應達成目標

* 可正確生成牆高與牆厚
* 可流暢瀏覽空間
* 相機高度預設 1.7m（可調整）
* 空間比例與 2D 一致
