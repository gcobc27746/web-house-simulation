# 1.1 Step 1 概述：2D 平面圖校正與牆線標註

## 核心理念

**2D 階段解決「比例尺正確 + 牆線正確」**

本產品的核心目標，不是建立華麗的 3D 模型，而是建立一個「可被信任」的空間決策工具。

2D 階段的價值在於：

* 確保比例尺正確
* 建立乾淨、可運算的向量模型
* 消除圖片視覺誤差

本階段不依賴 AI 自動辨識，而是透過使用者明確操作，確保最終資料精準可控。

---

## 主要目的

把「一張圖片」變成「有真實比例的 2D 平面底圖」，並在上面完成：

* 比例尺校正（Scale Calibration）
* 牆線向量化（Wall Tracing）
* 產生可被 3D 引擎使用的結構資料

完成後應產出：

* 以公尺為單位的牆壁邊緣線段資料
* 以公尺為單位的 polygon 外框（房間邊界）
* 已校正的比例資訊（px → meter）
* 可被序列化為 JSON 的結構資料

**重要**：本階段只記錄牆壁的邊緣線段，不處理牆厚。牆厚將在 3D 階段根據需求設定。

此資料將作為後續 3D 生成的唯一來源。

---

6. **1.6 牆線繪製模組** - 實作牆線繪製功能（依賴 1.5）
