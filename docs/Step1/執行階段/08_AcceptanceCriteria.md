# 1.8 驗收標準與測試

> **前置需求**：必須完成所有功能模組（1.4、1.5、1.6、1.7）的實作

## 驗收目標

根據以下標準驗證所有功能是否正確實作。

---

## 功能驗收標準

### 1. 比例尺校正準確度

**標準**：使用者校正後，任意再量測一段已知尺寸（例如另一扇門或床寬），誤差 < 2–3cm

**測試步驟**：
1. 上傳平面圖
2. 使用門框（90cm）進行比例尺校正
3. 量測其他已知尺寸（例如另一扇門、床寬等）
4. 計算誤差是否在容許範圍內

**通過標準**：誤差 < 2–3cm

---

### 2. 牆段封閉性

**標準**：牆段可完整封閉形成主要空間外框（polygon）

**測試步驟**：
1. 繪製多段牆線
2. 確認牆段形成封閉的多邊形
3. 驗證 polygon 資料正確生成

**通過標準**：封閉 polygon 正確生成，資料結構符合規範

---

### 3. 本地儲存功能

**標準**：編輯過程中自動儲存至 LocalStorage，重新載入頁面可恢復編輯狀態

**測試步驟**：
1. 進行編輯操作（上傳圖片、校正比例、繪製牆線）
2. 重新載入頁面
3. 驗證所有編輯內容正確恢復

**通過標準**：所有資料正確恢復，包括圖片資訊、比例尺、牆線

---

### 4. JSON 匯出/匯入功能

**標準**：可匯出 JSON 並再次載入進行編輯

**測試步驟**：
1. 完成編輯後匯出 JSON
2. 清除瀏覽器資料
3. 匯入 JSON 檔案
4. 驗證所有資料正確載入

**通過標準**：匯出和匯入功能正常，資料完整

---

### 5. JSON 格式規範

**標準**：JSON 格式符合定義的資料結構，包含 `meta` 版本資訊

**測試步驟**：
1. 匯出 JSON 檔案
2. 檢查 JSON 結構是否符合規範（參考先備知識/03_DataFormat.md）
3. 驗證所有必要欄位存在
4. 驗證 `meta.version` 欄位存在且格式正確

**通過標準**：JSON 格式完全符合規範

---

### 6. 幾何結構合法性

**標準**：polygon 不可自交叉，幾何結構合法

**測試步驟**：
1. 繪製可能自交叉的牆段
2. 驗證系統檢測出自交叉情況
3. 驗證系統阻止或提示使用者修正

**通過標準**：自交叉檢測正常運作

---

### 7. 座標單位轉換

**標準**：所有座標值正確轉換為公尺單位

**測試步驟**：
1. 完成比例尺校正
2. 繪製牆段
3. 檢查匯出的 JSON 資料
4. 驗證所有座標值為公尺單位（非像素）

**通過標準**：所有座標值為公尺單位

---

## 完整測試流程

### 端到端測試

1. **初始狀態**
   - [ ] 開啟應用程式
   - [ ] 顯示空白畫布和上傳按鈕

2. **圖片上傳**
   - [ ] 上傳 JPG 圖片 → 成功顯示
   - [ ] 上傳 PNG 圖片 → 成功顯示
   - [ ] 拖放上傳 → 成功
   - [ ] 上傳無效格式 → 顯示錯誤

3. **比例尺校正**
   - [ ] 點擊兩點量測 → 顯示量測線
   - [ ] 輸入 0.9m → 比例正確計算
   - [ ] 再次量測驗證 → 誤差 < 3cm

4. **牆線繪製**
   - [ ] 繪製單段牆線 → 成功
   - [ ] 連續繪製 → 牆段連接
   - [ ] 吸附功能 → 正常運作
   - [ ] Shift 對齊 → 正常運作
   - [ ] 選取和編輯 → 正常運作
   - [ ] 形成封閉 polygon → 自動檢測

5. **資料儲存**
   - [ ] 自動儲存 → LocalStorage 有資料
   - [ ] 重新載入 → 資料恢復
   - [ ] 匯出 JSON → 檔案下載
   - [ ] 匯入 JSON → 資料載入

6. **錯誤處理**
   - [ ] 檔案格式錯誤 → 顯示錯誤訊息
   - [ ] 資料格式錯誤 → 顯示錯誤訊息
   - [ ] LocalStorage 空間不足 → 顯示錯誤訊息

---
