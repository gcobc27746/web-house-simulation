# 2.1 Step 2 概述：2D → 3D 轉換與空間瀏覽

## 核心理念

**3D 階段解決「空間尺度感 + 走動體驗」**

本階段不是做華麗模型，而是基於 Step 1 的向量資料，提供可驗證比例與走動感的空間檢視工具。

---

## 主要目的

將 2D polygon 與牆線資料轉換成 3D 空間，並提供第一人稱瀏覽：

1. 可設定天花板高度
2. 正確生成地板與牆體
3. 提供 WASD + 滑鼠視角操作
4. 啟用碰撞避免穿牆

---

## 不變原則

- 所有幾何都來自 Step 1 JSON
- 不依賴原始圖片
- 不做自動推測
- 所有座標維持公尺單位
