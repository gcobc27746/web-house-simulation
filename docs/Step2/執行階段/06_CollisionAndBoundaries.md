# 2.6 執行任務：碰撞與邊界阻擋

> 前置：完成 `2.5`

## 任務目標

避免第一人稱相機穿牆，提供基本碰撞阻擋。

---

## 輸入

- `wallMeshes[]`
- 相機下一幀預測位置
- 碰撞半徑（角色 capsule/圓柱簡化）

## 輸出

- 修正後可用位置（不穿牆）
- 碰撞狀態（hit / no-hit）

---

## 實作步驟

1. 先實作簡化碰撞（AABB 或牆段平面投影）
2. 更新移動流程：先預測位置，再做碰撞修正
3. 撞牆時阻擋法向方向位移，保留切向滑動
4. 加入可視化 debug 開關（顯示碰撞盒/邊界）

---

## 完成標準

- [ ] 相機不會穿過牆體
- [ ] 牆邊移動時可自然滑動
