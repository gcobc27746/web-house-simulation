# Web House Simulation 介面現況與改版需求說明（可直接複製給其他 AI）

## 1) 目前介面（Current UI）結構盤點

### 整體版面
- 頁面採用**滿版高度 (`h-screen`) 的直向分層**：
  1. 最上方 Header（固定在頂部視覺層）
  2. 下方主工作區（Design 模式時為三欄式）
- 在 Design 模式下，主區域是**左窄欄 + 中央畫布 + 右側設定欄**。

### Header（上方）
- 左側：品牌區（圖示 + `SpatialPlanner` + `Project: Floorplan Simulation`）。
- 中間（桌機 `md` 以上顯示）：`Design` / `3D View` 分頁切換按鈕。
- 右側：主要切換按鈕（`前往 3D` / `回到 2D`）。

### 左側 Sidebar（工具主選單）
- 位置：**左側**。
- 寬度：`72px` 固定寬。
- 內容：6 個圖示按鈕（僅 icon，透過 title 提示文字）
  - 上傳（upload）
  - 校正（calibrate）
  - 牆線（wall）
  - 家具（furniture）
  - 圖層（layers）
  - 設定（settings）
- 行為：點選某個工具後，右側面板顯示對應設定內容。

### 中央工作區（Canvas 區）
- 位置：**中間主要區塊**（`flex-1`）。
- 內容：
  - 上半部：2D Canvas（可載入底圖、量測、畫牆、框選窗戶、選家具/移動家具）。
  - 下方：狀態列（高度 `32px`），顯示游標座標 X/Y、單位、縮放百分比。

### 右側 Panel（設定/工具細節）
- 位置：**右側**。
- 寬度：`320px` 固定寬。
- 內容依左側工具切換：
  - `upload`：圖片上傳 + 資料儲存（JSON 匯入匯出、清除）
  - `calibrate`：比例尺校正
  - `wall`：牆線繪製（開始/停止、連續模式、Undo/Redo、刪除）+ 窗戶標記子區
  - `furniture`：家具搜尋、分類、新增、旋轉、刪除
  - `layers/settings`：資料 JSON 檢視


### Design 模式「全部工具」完整清單（避免遺漏）
> 以下是 2D / Design 介面中可切換與可操作的完整工具與子功能：

1. **上傳（upload）**
   - 圖片拖拉上傳 / 點擊上傳（JPG、PNG）
   - 載入後作為底圖進入後續流程
2. **校正（calibrate）**
   - 兩點量測
   - 輸入真實距離建立比例尺
   - 可重新開始量測 / 清除校正（清除時會一併重置牆、窗、家具資料）
3. **牆線（wall）**
   - 開始/停止繪製牆段
   - 連續繪製（continuous）開關
   - Undo / Redo
   - 刪除選取牆段
   - 牆段與 polygon 數量狀態
4. **窗戶標記（wall 的子工具）**
   - 開始/停止窗戶模式
   - 框選牆段區域後建立窗戶
   - 窗型切換：落地窗 / 一般窗 / 氣窗 / 陽台窗（目前程式內建）
   - 刪除選取窗戶
5. **家具（furniture）**
   - 家具搜尋
   - 家具分類（全部 / 床 / 沙發）
   - 新增家具到畫布
   - 選取後旋轉（±15°）與刪除
6. **圖層（layers）與設定（settings）**
   - 目前兩者都顯示資料狀態面板（meta/image/scale/walls/windows/furniture JSON）
7. **資料儲存（位於 upload 面板）**
   - 匯出 JSON
   - 匯入 JSON
   - 清除本地資料（LocalStorage）

補充：
- Header 還有 Design / 3D 檢視切換。
- Canvas 底部有狀態列（座標、縮放、單位）。

### 目前 Layout 比例（以常見 1440px 寬估算）
- 左側工具欄：`72px`（約 5%）
- 右側設定欄：`320px`（約 22%）
- 中央工作區：`1440 - 72 - 320 = 1048px`（約 73%）
- 也可簡化理解為：**左固定窄欄 + 右固定中欄 + 中央彈性欄**。

### 目前交互痛點（你提出的重點）
- 工具操作需要「**左側切換工具**」+「**右側再調細節**」，操作路徑被拆成兩地。
- 牆體工具與窗戶工具的模式切換分散，心智負擔較高。
- 工作區周邊資訊偏多，不利於「快速、連續」作業。

## 2) 你希望的新介面（Target UI）方向

### 核心目標
- 把工作流改成像 Photoshop / 舊版小畫家：
  - **單一工具列選主工具**
  - **同工具的次模式在鄰近位置切換**（不要分散到另一側）
- 以「畫布優先」為主，減少非必要元件，提升專注度與速度。

### 目標操作模型（建議）
1. 使用者先在左側（或單一工具欄）選主工具。
2. 主工具被選中後，在同一區塊直接出現「次工具/模式」：
   - 牆體工具：
     - 連續牆體模式
     - 單段式模式
   - 窗戶工具：
     - 落地窗 / 天窗 / 一般窗 / 氣窗（作為同工具延伸選項）
3. 使用者不用再跨到右側找細項設定，降低切換成本。

### 你要的工具語意（可給設計 AI 直接用）
- **牆體拉取工具**
  - 同一支工具筆觸，內含兩種子模式：
    - 連續牆體
    - 單段式
- **窗戶選取/挖窗工具**
  - 先選牆段區段，再在範圍內建立窗戶開口
  - 窗戶類型是同工具的延伸選項：
    - 落地窗
    - 天窗
    - 一般窗
    - 氣窗

## 3) 可直接貼給另一位 AI 的需求敘述（精簡版）

請協助我重構目前的 Web House Simulation 編輯介面，目標是「工作區簡化、工具集中、降低跨區切換」。

目前是三欄式：左側 72px 工具 icon 欄、中間畫布、右側 320px 設定面板。現況問題是：使用者要先在左側選工具，再到右側調同一工具的細節，流程太分散。

我希望改成接近 Photoshop / 舊版小畫家的工具邏輯：主工具與其子模式要在同一區域完成，不要拆成左選工具、右調模式。

本專案要一起被整合簡化的工具包含：
1) 上傳照片（拖拉/點選）
2) 比例尺校正（兩點量測 + 輸入真實距離）
3) 牆體工具（連續牆體 / 單段式）
4) 窗戶工具（窗型切換，包含落地窗、天窗、一般窗、氣窗；註：現行程式有陽台窗）
5) 家具工具（搜尋/分類/新增/旋轉/刪除）
6) 資料工具（匯出 JSON / 匯入 JSON / 清除本地）

請提出新版資訊架構、版面配置與互動流程，重點是：
- 畫布優先、減少不必要元件
- 工具切換與次模式切換集中在同一區
- 快速標示目前工具狀態（主工具/子模式/參數）
- 比現在更少步驟完成相同操作

## 4) 可直接貼給另一位 AI 的需求敘述（完整版）

我目前的編輯器介面是三欄式：
- 左欄：72px icon 工具列（上傳、校正、牆線、家具、圖層、設定）
- 中央：主要畫布區（2D 操作）
- 右欄：320px 設定面板（依左側工具切換不同內容）

這個設計的主要問題是：同一任務需要在左右兩邊來回切換。舉例來說，先在左邊選「牆線」，再到右邊切「連續模式」或其他細節；窗戶工具也是類似狀況，工具和細項分散在不同區域，造成操作負擔。

我想要一個更精簡、工具導向的介面，參考 Photoshop 或舊版小畫家的工具列概念：
- 主工具在同一條工具列
- 子模式/變體（例如連續繪製、單段繪製）直接掛在主工具旁邊或浮出面板，不要放到遠端設定欄
- 使用者一眼可以看出目前是「哪個主工具 + 哪個子模式」

我希望改版時不要只優化牆體與窗戶，請把整個 2D Design 工作流都納入：
1. 上傳照片工具（含拖拉與點選）
2. 比例尺校正工具
3. 牆體拉取工具（連續/單段）
4. 窗戶工具（落地窗、天窗、一般窗、氣窗；並可對應現有窗型）
5. 家具工具（搜尋、分類、新增、旋轉、刪除）
6. 資料管理工具（JSON 匯入/匯出、清除本地）

我希望你幫我設計：
- 新版 Layout（例如單側工具欄 + 小型情境面板 + 大畫布）
- 工具列層級（主工具、子模式、狀態指示）
- 操作流程（從選工具到完成一次牆體/窗戶操作）
- 相較現況可減少哪些步驟
- 哪些目前元件可合併或移除（以精簡為優先）

整體方向：減少 UI 元件數量、提升畫布面積與操作連續性，讓它像專業繪圖工具那樣直覺快速。
